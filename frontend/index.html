                Stage 4

                Data Warehouse + OLAP Analytics

                What is a Data Warehouse? A data warehouse is a centralized repository optimized for analysis. Our warehouse contains 100,000 transaction records stored in a star schema—one fact table (transactions) connected to four dimension tables (date, merchant, location, transaction type). This structure enables multidimensional queries: "What is fraud rate by merchant in Delhi during weekends?" OLAP (Online Analytical Processing) pre-calculates fraud rates across these dimensions for instant analytics.

                Why Star Schema? It normalizes dimensions to avoid data redundancy while denormalizing the fact table for fast queries. Our schema creates fraud_rate_by_date, fraud_rate_by_merchant, fraud_rate_by_location, and fraud_rate_by_transaction_type views—enabling business intelligence dashboards.

                  Stage 5

                  Live Prediction

                  How to Use: Enter a transaction's details to predict fraud risk. Date/Time: Use dates in the range Sept 22 - Oct 21, 2024 (when historical fraud varied 5-14% daily). Amount (₹): Try ₹10,000 (low-risk) to ₹300,000 (high-risk) to see probability change. Merchant ID: Top fraudulent merchants: M0001, M0002, M0003 (high fraud risk); others: M0100-M0999 (lower risk). Location: High-fraud cities: MUMBAI, DELHI (10-12% fraud rate); low-fraud: SURAT, PUNE (5-7% fraud). Type: Use "transfer" or "refund" (transfer has 2x higher fraud rate than refund). High amounts + high-fraud merchant + metro location = higher fraud probability.
